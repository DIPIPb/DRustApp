# RustApp backend + панель (Vercel)

Заменяет `court.rustapp.io` в плагине `RustApp.cs` на твой собственный бекенд + веб-панель
(серверы / чат / репорты / баны / муты), без античит-функционала (HWID, heartbeat, скриншоты — убраны).

## 1. Разворачивание

1. Залей эту папку в GitHub-репозиторий.
2. На vercel.com → New Project → импортируй репозиторий.
3. В настройках проекта → Storage → **Create Database** → Postgres (Vercel Postgres или подключи Neon).
   Vercel сам добавит переменные окружения `POSTGRES_URL` и т.д.
4. Добавь переменную окружения `BOOTSTRAP_SECRET` — любую длинную случайную строку
   (нужна один раз, чтобы создать первого админа).
5. Deploy.

## 2. Накатить схему БД

Открой вкладку своей базы на vercel.com → **Query** (или подключись любым Postgres-клиентом
по `POSTGRES_URL`) и выполни содержимое `schema.sql`.

## 3. Создать первого админа

```bash
curl -X POST https://<твой-домен>.vercel.app/api/admin/bootstrap \
  -H "Content-Type: application/json" \
  -d '{"secret":"<BOOTSTRAP_SECRET>","username":"admin","password":"надёжный-пароль"}'
```

После этого — **обязательно удали или закомментируй `api/admin/bootstrap.js`** и задеплой заново
(эндпоинт больше не нужен и не должен висеть в проде).

## 4. Войти в панель

Открой `https://<твой-домен>.vercel.app/` — увидишь форму логина. Заходи под созданным аккаунтом.

## 5. Привязать Rust-сервер (плагин)

1. В панели → вкладка **"Привязать сервер"** → жми "Сгенерировать код привязки". Получишь одноразовый код.
2. В `RustApp.cs` поменяй:
   ```csharp
   private const string BaseUrl = "https://court.rustapp.io";
   ```
   на:
   ```csharp
   private const string BaseUrl = "https://<твой-домен>.vercel.app";
   ```
3. Пересобери/перезалей плагин на сервер, вызови pairing с этим кодом
   (в оригинале это происходит через chat-команду/консольную команду, которая шлёт
   `POST /plugin/pair?code=<код>` — она уже осталась в коде плагина, просто теперь бьёт в твой домен).
4. Плагин сохранит полученный `token` в свой датафайл и дальше будет слать
   state/chat/reports/ban/unban/mute на твой бекенд с заголовком `x-plugin-auth: <token>`.

## Что реализовано

- `POST /plugin/pair` — привязка сервера, выдача токена
- `PUT /plugin/state` — снапшот онлайн-игроков
- `POST /plugin/chat` — чат-сообщения → видно во вкладке "Чат"
- `POST /plugin/reports` — репорты игроков → видно во вкладке "Репорты"
- `POST /plugin/ban` / `POST /plugin/unban` — баны (пишутся в БД, таблица `bans`)
- `POST /plugin/player-mute/mute-player` / `unmute-player` / `GET get-active` — муты

## Что НЕ реализовано (сознательно, по твоей просьбе)

Всё, что было в старой панели DIPRUST про HWID-античит: heartbeat, HWID-баны, скриншот-реквесты,
вызов на "проверку" — убрано полностью. Осталась только логика самого RustApp-плагина
(чат/репорты/статус/баны/муты) плюс обычная авторизация в панель.

## Ограничения текущей версии (что доделать при желании)

- `signage`, `kills`, `alerts`, `custom-alert`, `contact`, `wipe`, `sleeping-bag` — сейчас просто
  отвечают `200 OK` и ничего не сохраняют (плагин не падает, но данные никуда не пишутся).
  Если что-то из этого нужно — говори, добавлю таблицы и вывод в панель.
- Список игроков онлайн (`players`) собирается, но отдельной вкладки в панели под него нет — легко добавить.
- Пагинация в чате/репортах простая (последние N записей), без фильтров по датам.
